# Apex Ledger | Commercial Accounting Platform & Custom Software Showcase

A modern, production-grade business management and accounting software platform prototype. It allows potential clients to experience a fully functional, interactive in-memory preview of 14 ERP modules and submit custom software specifications for their business.

---

## 🚀 Key Highlights

- **Interactive In-Memory Preview:** Realistic demo data across 14 modules with pure ephemeral session storage (no client data is permanently saved).
- **Role-Based Access Control (RBAC):** 4 demo login profiles (Owner, Branch Manager, Accountant, Cashier) with password checks and permission restrictions.
- **Custom Software Intake:** Interactive specification generator and quote calculator for bespoke client implementations.
- **Automated Windows Installer:** One-click batch (`install.bat`) and PowerShell (`scripts/installer.ps1`) deployment scripts for local client machines.
- **Modern Architecture:** React 18, TypeScript, Vite 5, Tailwind CSS, Recharts, Lucide Icons, and Zod.

---

## 💻 Tech Stack

- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide React
- **Build Tool:** Vite 5
- **Routing:** React Router v6
- **Forms & Validation:** React Hook Form + Zod
- **Data Visualizations:** Recharts
- **Testing:** Vitest + React Testing Library

---

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run automated tests
npm run test

# Check TypeScript types
npm run type-check

# Build for production
npm run build

# Preview production build locally
npm run preview
```
